# 第361章 问

九月二十一号，星期六。

那天陈屿没有去养老院。

他上午从省城开车回县城，一点半到家，吃了一碗剩下的面。母亲在院子里晒被子，父亲去工地上值班——他今年五十四，工地上给他排的是隔天一班，一班十二小时。

下午两点多，母亲进屋，把被子的竹竿收了。

陈屿在堂屋的八仙桌前面坐着。

桌上摊着一个本子和一支笔。

那是九月新换的那个硬皮本，第二页「未核实」底下九条。

第一条：这块表是哪儿来的。

这一条他二〇一七年就写上去了，写了七年，一直是空的。

九月十四号从养老院回来那天晚上，他把这一条底下补了一句：「沈说：一九九八年七月二十二日早上，一个姓林的照相的，从裤子口袋里掏出来给他。上衣口袋里是上海牌。」

补完他盯着这一句看了很久。

沈墨说的那块表，是给沈墨的。

那他手上这一块呢？

「妈。」

「嗯。」

「我问您一件事。」

母亲把抹布放下，在他对面坐了。

她今年五十二。二〇一四年出的那场车祸，右腿的钢板二〇一六年取了，走路还是有一点点跛，天阴的时候会酸。这几年她在合作社里管账，一个月两千八，家里不缺这个钱，她不肯不去。

「你问。」

陈屿从衬衫口袋里，把那块表拿出来，放在桌上。

铜壳，没有链子，表面朝下。

母亲看了一眼。

「这个啊。」她说。

「妈，这块表是哪儿来的？」

母亲把手在围裙上擦了一下。

「祖传的。」她说。

「祖传是从哪儿传的？」

「你外公那儿传的。」

「外公从哪儿来的？」

母亲愣了一下。

「他爹那儿。」

母亲说这三个字的时候，眼睛看的是桌上那块表。

她没有伸手去碰。

这十四年，陈屿注意过一件事：家里所有人都碰过这块表，父亲、小舅、周知意、王浩，连沈默都拿在手里翻过一次。

只有母亲一次都没有碰过。

「我太外公？」

「嗯。」

陈屿把笔拿起来，在本子上写：「太外公。」

写完他抬起头。

「妈，我太外公叫什么？」

母亲的手停在围裙上。

她想了很久。

「你太外公我没见过。」她说，「我出生那年他就没了。」

「那您怎么知道表是他传的？」

「你外公说的。」

「他什么时候说的？」

母亲又想了很久。

「记不清了。」

「妈，您再想想。」

「记不清就是记不清。」母亲说，「你外公跟我说的话，一辈子加起来不到一千句。」

这句是真的。

陈屿这一世见过外公一次，那一次老人只问了他一句话，问完就没有再说。母亲讲过很多回：她父亲这个人，一天到晚在暗房里，出来就是吃饭，吃完接着进去。她十九岁那年谈对象，把陈建军领回家，老人从暗房里出来看了一眼，说了一个字：「好。」

然后又进去了。

堂屋里安静下来。

外面院子里有一只鸡在叫。隔壁在装修，电钻的声音一阵一阵。

陈屿把那块表翻过来。

铜面朝上，干净的，什么都没有。

他这十四年，问过这个问题两次。

第一次是二〇一〇年秋天，他十岁。那次母亲说的是「祖传的」。

第二次是二〇一七年冬天，他十七岁，第三本账本上还留着那一条：「问表来历。答：祖传。追问：外公的爹。答：应该是。」

那一次他是在饭桌上问的，问得很随便，装成是学校里布置了一个「家庭老物件」的作业。

母亲当时正在剥蒜。

她剥完手里那一头，才回了那三个字。

「应该是。」

那三个字他后来在账本上圈了一个圈。圈完他在旁边写：「不追。太急会露。」

那个「应该是」他当年就注意到了。

七年以后，他今天第三次问。

母亲说的还是「祖传的」。

但是这一次她想了两次，每一次都想了很久。

「妈。」

「嗯。」

「外公是什么时候开始戴这块表的？」

母亲抬起头。

这个问题她没有想。

她答得很快。

「一九九八年七月以后。」她说。

说完她自己也听见了。

她的手在桌上按了一下，像是要把这句话按回去。

但是已经说出来了。

# 第362章 一九九八年七月以后

母亲说完这一句，自己也停了一下。

她大概也听见自己答得太快了。

「妈，您怎么记得这么清楚？」

母亲把手放在桌上。

那双手很粗，指关节大，指甲剪得很短。她卖了十九年菜，二〇一九年才不摆摊。

「因为那年发水。」她说。

一九九八年这三个字，在这个家里是有分量的。

陈屿这十四年，听见过它三次。

第一次是二〇一二年，父亲喝了点酒，说了一句「九八年那水，我这辈子忘不掉」。

第二次是二〇二二年七月二十一号，他跟着父亲走那条已经没有的街，父亲说：「水到我这儿。」他用手在自己腰上比了一下。

第三次是今天，母亲说的。

「嗯。」

「发水那阵子我十七。」母亲说，「我记得七月二十一那天，你外公一晚上没回来。第二天早上回来的，浑身是泥。」

「他去哪儿了？」

「拍照。」

「拍什么照？」

「他不说。」

「一句都不说？」

「一句都不说。」母亲说，「我妈问他去哪儿了，他说『街上』。我妈问街上干什么，他就不吭声了。」

「后来问过吗？」

「后来我妈问过好几回。」母亲说，「问到第四五回，他发了一次火。」

「他发火？」

「他一辈子发过三次火。」母亲说，「那是第一次。」

「他说什么了？」

母亲想了一会儿。

「他说：『别问了。』」

陈屿在本子上写。

「妈，那这跟表有什么关系？」

母亲想了一会儿。

「那年八月，我看见他手上多了一块表。」她说。

「怀表？」

「怀表。就是你手上这块。」

「他以前戴什么？」

「上海牌。」母亲说，「戴了好多年了。」

「多少年？」

「我记事起他就戴。」

「后来呢？」

「后来就不戴了。」母亲说，「九八年八月以后，他就戴这块怀表，揣在裤子口袋里，用一根鞋带拴在裤袢上。」

「拴着？」

「拴着。」母亲说，「怕丢。」

陈屿把笔停住。

一个人怕丢一样东西，会有两种怕法。

一种是怕丢了心疼。

另一种是怕丢了以后，被别人捡到。

陈屿把笔停住。

沈墨在养老院里说的那句话，他写在本子上：「上衣口袋里那块是他自己的，上海牌，走得很准。」

这一句和母亲这一句对上了。

对得严丝合缝。

而这两个人，一个七十九岁，记不住人名；一个五十二岁，从来没有听说过沈记钟表这个铺子。

「妈，那块上海牌呢？」

母亲又想。

「你外婆走的时候，家里的东西大部分给了你大姨。」她说，「后来二〇一八年老屋拆了，剩下的都在楼上那个纸箱里。」

「哪个纸箱？」

母亲往楼上指了一下。

「西屋那个，蓝盖子的。」

陈屿站起来。

「妈。」

「你干什么？」

「我上去看看。」

母亲在他后面说了一句。

「小屿。」

他站在楼梯口回头。

「一块表，」母亲说，「你怎么这么大兴致。」

陈屿在楼梯上站着。

母亲坐在八仙桌前面，逆着光，看不清脸。

「妈，我从小就爱问这个。」他说。

「你从小就爱问这个。」母亲说。

她说这一句的时候，语气很平。

平得有一点不对。

一个母亲说「你从小就爱问这个」，正常的语气应该是笑着的，或者是嫌烦的。

她这一句是念出来的。

像是她心里早就准备好了这一句，准备了很多年，就等着有一天用上。

陈屿上了楼。

上到一半他回头看了一眼。

母亲还坐在八仙桌前面，一动没动。

桌上那块表，她还是没有碰。

# 第363章 上海牌

西屋那个纸箱是二〇一八年封的，胶带都脆了，一撕就断。

箱子里的东西不多。

一件深蓝色的中山装，叠得很整齐，肩膀上有一块洗不掉的黄印。

一副老花镜，一条腿断了，用胶布缠着。

一个铁皮饼干盒。

三个相框，玻璃都碎了，照片抽走了。

一本《新华字典》，一九七九年版，扉页上写着「林建国」三个字。

字写得很硬，笔画短，收得快。

陈屿在这个字迹上停了两秒。

他见过这个字迹。二〇二二年正月初七，父亲从阁楼上搬下来一个箱子，箱子里有一本外公的记账本，从一九八六年记到一九九六年。那本账的封底内侧，有一行不属于账的字：

「七月廿一 两下」。

同一个人的手。

陈屿把饼干盒打开。

里面有：一把钥匙，两张已经作废的存单，一枚纪念章，一叠票据，还有一块表。

上海牌。

方形表壳，镀金掉了大半，表带是后来换的，塑料的，断了一截，用一根鞋带接的。

陈屿把它拿起来。

停在十点二十五。

他把它翻过来看后盖。

后盖上有字。不是刻的，是划的——用什么尖东西划上去的，歪歪扭扭：

「78.4」

一九七八年四月。

那一年外公三十一岁。

一九七八年四月，一块上海牌手表要一百二十五块，还要票。

一个三十一岁的照相学徒，攒一百二十五块要多久，陈屿算不出来。但是他知道一件事：一个人会在一块表的后盖上划下买它的月份，说明这块表对他来说是一件大事。

一件大事戴了二十年。

然后在一九九八年八月，忽然不戴了。

换成了一块什么标记都没有的铜表，用鞋带拴在裤袢上。

陈屿把上海牌放在窗台上，把自己那块怀表放在旁边。

两块表并排。

一块方的，一块圆的。一块镀金的，一块铜的。一块划着日期，一块什么都没有。

他在窗台前面站了很久。

然后他做了一件事。

他把怀表翻过来，看后盖。

这个动作他这十四年做过无数次。

后盖是光的。没有刻字，没有划痕，没有编号，没有厂标。

一块表，什么标记都没有。

这件事他从十岁起就知道，但是他从来没有觉得奇怪。

因为一个十岁的孩子拿到一块祖传的表，他只会想「这块表能干什么」，不会想「这块表是哪个厂造的」。

一个四十岁的程序员也不会想。因为他忙着搞清楚回滚怎么用。

到今天他二十三岁，第十五年。

他忽然想清楚一件事：这块表不是任何一个厂造的。

因为它没有可以造的地方。

他把两块表都拿起来，掂了掂。

上海牌沉，怀表轻。

上海牌里面有机芯，能听见极轻的一点响——虽然停了很多年，晃一晃还会有簧片碰壳的声音。

怀表晃起来，什么声音都没有。

它是实心的。

这一点他二〇一二年就知道了。那年他十二岁，拿一把小螺丝刀试过撬后盖，撬了四十分钟，后盖纹丝不动，连一道缝都没有。

沈墨那块空表也一样。

十四年，两块表，谁都没有打开过。

他把上海牌放回饼干盒，把饼干盒放回纸箱。

盖上盖子的时候他想起母亲刚才那一句：「一块表，你怎么这么大兴致。」

他这十四年，从来没有在家里人面前提起过这块表。

一次都没有。

那母亲是怎么知道他「从小就爱问这个」的？

# 第364章 第二个本子

九月二十二号，星期天。

陈屿去了大姨家。

大姨住在县城东边的老小区，六楼，没有电梯。她今年五十六，退休三年，儿子在杭州。

外婆二〇一六年走的时候，家里的老东西大部分归了她。

「小屿？」大姨开门的时候愣了一下，「你怎么来了。」

「大姨，我来找一样东西。」

「找什么？」

「外公照相馆的东西。」

大姨姓林，叫林秀娟，比母亲大四岁。她跟母亲的关系一般——二〇一六年外婆走的时候分东西，两个人为一台缝纫机说过几句难听的。这几年缓过来了，逢年过节还走动。

她对陈屿一直不错。二〇一八年他考上大学，大姨给了两千块。

大姨把他让进屋。

「照相馆那些破烂啊。」她说，「二〇〇四年关门的时候，能卖的都卖了。剩下的在阳台上那两个纸箱里，你自己翻。」

阳台上那两个纸箱，一个装的是相框和背景布，另一个装的是纸。

纸很多。

发票，收据，一叠没用完的相片袋，几本旧挂历。

翻到底下的时候，陈屿摸到两个硬皮本。

第一本他见过。那是二〇一八年他在外婆家翻出来的那本顾客登记，从一九九七年记到二〇〇四年，每一页画着表格：日期、姓名、张数、尺寸、取件日期、金额。

那一本他二〇一八年翻过三遍，一九九八年七月那几页翻得最细。

七月十九号有两户。

七月二十号有一户，姓周，证件照两张。

七月二十一号，空白。

七月二十二号，空白。

一直空到七月三十一号。

他当年的结论是：发水，店关了。

这个结论没有错。

错的是他以为「顾客登记」就是全部。

第二本他没有见过。

第二本比第一本小一圈，深蓝色的封皮，边角磨圆了。

封皮上贴着一张白纸条，上面用钢笔写了四个字：

「底片登记」。

四个字，还是那个手。

陈屿在阳台上蹲着，两只手捧着这个本子，忽然觉得有点冷。

一个照相馆有两本账，这件事本身不奇怪。顾客登记是给客人看的，底片登记是给自己看的。

奇怪的是，二〇〇四年关门的时候，外公把顾客登记留在了家里，把底片一箱一箱交给了县照相馆。

而这本底片登记，他既没有交，也没有留在家里显眼的地方。

它压在阳台上一个纸箱的最底下，上面盖着一叠没用完的相片袋。

盖了二十年。

陈屿把这个本子拿出来的时候，手指在封皮上停了两秒。

他翻开第一页。

第一页是一九九七年三月十四日。

格式跟顾客登记不一样。这个本子的表格是：日期、卷号、张数、内容、顾客。

一卷胶卷三十六张，外公一卷一卷地记。

「97.3.14 / 001 / 36 / 结婚（李）12张 全家（周）8张 证件16张 / 三户」

「97.3.19 / 002 / 36 / 证件28张 满月（吴）8张 / 两户」

一页十行，一年大概三十页。

陈屿把本子往后翻。

一九九七，一九九八。

翻到一九九八年七月。

「98.7.3 / 049 / 36 / 证件 / 多户」

「98.7.11 / 050 / 36 / 毕业合影（三中）1张 证件30张 / 两户」

「98.7.19 / 051 / 36 / 证件18张 / 多户」

下一行。

每一行的字都很小，很挤，写满为止。

外公记账是一个抠字眼的人。他连「证件16张」都要写清楚是十六张。

陈屿的手停住了。

「98.7.22 / 052 / 3 / — / —」

# 第365章 三张

「98.7.22 / 052 / 3 / — / —」

日期：一九九八年七月二十二日。

卷号：052。

张数：三。

内容：一道横杠。

顾客：一道横杠。

陈屿在阳台上蹲着，把这一行看了很久。

这个本子从一九九七年三月记到二〇〇四年八月，一共三百四十七卷。

三百四十七卷里，只有这一卷是三张。

其余全是三十六，偶尔有二十四的——那是短卷。

三百四十七卷里，只有这一卷的「顾客」栏是空的。

其余全有名字，或者写「多户」。

他把整本从头翻到尾，一页一页地数。

数了四十分钟。

三百四十七卷。

一九九七年三月到二〇〇四年八月，七年五个月。

其中：三十六张的三百一十一卷，二十四张的三十五卷，三张的一卷。

陈屿把这一页拍了照。

然后他往后翻。

七月二十二以后，下一条是七月三十一日。

中间隔了九天。

这九天里，林记照相没有拍过一张照片。

「大姨。」

大姨在客厅看电视，把声音调小了。

「什么事？」

「一九九八年发水，照相馆停了几天？」

「哪年？」

「九八年。」

大姨想了一下。

「九八年我二十九，在纺织厂上班。」她说，「照相馆进了水，柜台泡了，放大机也泡了。爸修了半个多月才重新开门。」

「半个多月？」

「大概吧。」

「大姨，那半个多月照相馆一个人都没接？」

「接不了。」大姨说，「柜台泡了，暗房在后面，地势低，水最深的时候到膝盖。药水瓶全漂起来了。」

「那损失多少？」

「不知道。我妈那阵子天天愁。」大姨说，「那年冬天我们家过年没买肉。」

陈屿把本子举起来。

「大姨，这个本子上写的是，七月二十二拍了三张，然后七月三十一就恢复了。」

「那就是九天。」

陈屿看着她。

「妈，那它到底是哪儿来的？」

母亲的手指在那张照片上停着。

停在坡上那个人的位置。

「我不知道。」她说，「我只知道你外公是九八年七月以后才有的。」

「您没问过他？」

「问过一次。」

「他怎么说？」

母亲抬起头。

「他说：『不是我的。』」

「那是谁的？」

「我没有再问。」母亲说。

「为什么不问？」

母亲把第三张照片重新翻过来，正面朝上。

她看了一眼，又移开了。

「因为他那天在哭。」她说。

陈屿坐在那儿。

「我爸——你外公，我这辈子见他哭过一次。」母亲说，「就是那一次。」

「哪一年？」

「二〇〇九年冬天。」母亲说，「他那时候已经病了。有一天晚上我去送饭，进门看见他坐在床上，手里拿着这块表。」

「他在哭？」

「他没出声。」母亲说，「他就是坐在那儿，眼泪掉下来。」

「您问他了？」

「我问了。」母亲说，「我问他：『爸，这表到底是谁的。』」

「他说什么？」

母亲把手放在膝盖上。

「他说：『不是我的。』」她说，「就这四个字。说完他就把表放回枕头底下了。」

三个月以后，二〇一〇年三月，老人走了。

枕头底下那块表，被陈建军收拾遗物的时候摸了出来。

放在里屋的桌上。

一个刚满十岁的孩子伸手把它拿走了，说：「它是我的。」

那天晚上，陈屿出了门。

他开车到老街，把车停在桥头，走过去。

老街二〇一九年拆了一半，坡还在，那段矮墙还在。矮墙外面现在是一条水泥路，路那边是河堤。

九月底的夜里有风。

他在那段墙外面坐下来，背靠着墙。

墙根底下有草，秋天的草，扎人。

他坐下去的时候踩到一个易拉罐，踢开了。

远处河堤上有一盏路灯，光照不到这儿。

坐到十二点，坐到两点，坐到四点。

这四个小时他什么都没有想。

他这十四年很少有什么都不想的时候。他的脑子从二〇一〇年七月起就没有停过——记新闻、记日期、记价格、记谁在哪一年说过什么。他的账本写了八本，一千多页，一页不落。

今天夜里他坐在这段墙外面，脑子是空的。

不是想不出来。

是他忽然发现，他这十四年查的所有事，都是别人的事。

小舅的公司，王浩的仓库，父亲的工地，周知意的班，沈墨的十三块表，一九九八年七月二十一号那天街上有几个人。

只有一件事他从来没有查过。

四点的时候他把三张照片从口袋里拿出来，摸了摸，没有看——太黑了，看不见。

「小满。」

【我在。】

「你知道这块表是哪儿来的吗？」

铜面上停了很久。

【不知道。】

「你从什么时候开始在里面的？」

【不知道。】

「你第一次跟我说话是二〇一〇年七月十五号。」陈屿说，「那之前呢？」

铜面上又停了很久。

【那之前，我在等。】

「等什么？」

【等有人问我一句话。】

陈屿把表握在手里。

「哪一句？」

铜面上的字浮出来，很慢。

【「你是谁。」】

陈屿在那段墙外面坐着，天开始亮了。

他这十四年，问过这块表几千个问题。

这一句他一次都没有问过。
