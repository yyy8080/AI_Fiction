# 归档：压缩版 v1（第21–230章）

这里保存的是**旧版**《回滚人生》第21–230章正文与配套细纲。

旧版用约200章（31–230）就把故事推进到 2025 年双结局，节奏过快：初中三年被压成十余章，大学四年被压成三十章，卷四的沈墨真相与上市几乎是并排发生的。

自 2025 年 8 月起，全书从**第21章**重新规划，目标约 **500 章**，时间线拉长：

- 卷一续·初中 21–80（2012秋–2015夏）
- 卷二·高中 81–180（2015秋–2018夏）
- 卷三·大学 181–300（2018秋–2022夏）
- 卷四·入行 301–420（2022秋–2025春）
- 卷五·结算 421–500（2025—）

新总纲见 [`../../outline-21-500.md`](../../outline-21-500.md)。

**第1–20章未变动**，仍是正式版本。

本目录内容仅供参考，**不作为 continuity 依据**。旧版中出现的时间线、章节号、人物进度均已作废；若与新总纲冲突，一律以新总纲为准。
