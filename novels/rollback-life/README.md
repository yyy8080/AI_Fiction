# 回滚人生

重生都市文 · 全五卷（第1–230章）

## 设定摘要

- 主角陈屿：前世 40 岁苦逼程序员，加班改需求猝死，最后一句「好的，马上改」
- 穿越至 2010 年夏天，十岁，小学五年级
- 金手指：祖传怀表内残缺系统 `ROLLBACK`；小满为离线镜像
- 规则：四道锁（身份锁、回滚税、修正力、人心锁）；重大历史节点 `[LOCKED]` 不可改
- 命名纪律：正文不出现真实企业名，一律谐音（威信、掏宝、米厂、某音等）
- 时间线：自 2010 起紧跟现实年份推进；第1–230章时间跨度约 **2010 – 2025+**
