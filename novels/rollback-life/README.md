# 回滚人生

重生都市文 · 全五卷 · **约500章** · 扩写至约500章进行中

## 设定摘要

- 主角陈屿：前世 40 岁苦逼程序员，加班改需求猝死，最后一句「好的，马上改」
- 穿越至 2010 年夏天，十岁，小学五年级
- 金手指：祖传怀表内残缺系统 `ROLLBACK`；小满为离线镜像，只以【】说话
- 规则：四道锁（身份锁、回滚税/记忆磨损、修正力、人心锁）；重大历史节点 `[LOCKED]` 不可改，只能把人往边上拽
- 命名纪律：正文不出现真实企业名，一律谐音（威信、掏宝、米厂、某音、某手、付之宝、余额堡、茆台、必特币、星创板、深言、某为、华威等）
- 时间线：自 2010 起紧跟现实年份推进，全书跨度 **1998 / 2010 – 2025+ / 2040**
- 调性：前期压抑，爽点后置；曲线救国，不无脑暴富；投机有限
